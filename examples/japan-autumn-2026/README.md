# Япония, 2–13 ноября 2026

Канонический пакет поездки, перенесённый из пользовательского HTML-плана `japan_itinerary_02-13_nov_2026.html` в актуальный формат Travel Planner. Он сохраняет шесть баз, 12 дней, транспортные варианты, погодные сценарии, еду, бюджетный ориентир и открытые действия.

Это черновик: внешние ссылки взяты из исходного документа без нового поиска, расписания и бронирования не подтверждены. Все 18 встроенных фотографий перенесены без изменения bytes в `media/`: по одной или две на каждый из 12 дней. Авторы, лицензии, alt-тексты и ссылки на оригиналы сохранены из документа; удалённые страницы повторно не проверялись. См. [происхождение и лицензии фотографий](media/README.md). Фотографии не покрываются MIT-лицензией кода проекта.

Все 12 дней оформлены общим шаблоном из [PR #11](https://github.com/WorkKroG/travel-planner-skill/pull/11): жёлтая шапка, фотографии, три факта, сценарии и хронология с круглыми иконками. Необязательные `period` задают части дня без перестановки событий; источники и авторство собраны внизу дня. Фактическое содержимое 242 событий сохранено. Открываемый результат — [HTML-маршрут](outputs/itinerary.html).

Проверка и воспроизводимая сборка из корня репозитория после установки helpers:

```sh
trip_smoke_dir="$(mktemp -d)"
cp -R examples/japan-autumn-2026 "$trip_smoke_dir/trip"
.venv/bin/travel-planner check "$trip_smoke_dir/trip"
.venv/bin/travel-planner render "$trip_smoke_dir/trip" --output "$trip_smoke_dir/japan.html" --at 2026-09-07T17:44:11+00:00
```

Для проверки команды `init` используйте отдельную временную директорию и не перезаписывайте этот пример.

Переносимый bundle включает пять канонических файлов и `media/`. Готовый `outputs/itinerary.html` уже содержит фотографии и открывается как самостоятельный файл. Пересборка с указанным временем воспроизводит committed HTML; SHA-256: `a348c53562959f4c024ba7036b3d8a49510c4e600400dfe316bd4484d24c1d58`. Фиксированное время нужно только для воспроизводимости примера и не означает свежую проверку поездки.

Для собственного маршрута используйте [инструкцию тестирования в новом чате](../../docs/ROUTE_BUILD_TEST.md). Визуальные проверки браузера, мобильной раскладки и печати остаются в [release checklist](../../docs/RELEASE_CHECKLIST.md).
