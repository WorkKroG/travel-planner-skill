# Япония, 2–13 ноября 2026

Канонический пакет поездки, перенесённый из пользовательского HTML-плана `japan_itinerary_02-13_nov_2026.html` в актуальный формат Travel Planner. Он сохраняет шесть баз, 12 дней, транспортные варианты, погодные сценарии, еду, бюджетный ориентир и открытые действия.

Это черновик. К исходным ссылкам добавлены официальные страницы и карты основных пунктов; объём новой проверки описан в [аудите ссылок](LINK_AUDIT.md). Расписания, цены, доступность и бронирования заново не подтверждены. Все 18 встроенных фотографий перенесены без изменения bytes в `media/`: по одной или две на каждый из 12 дней. Авторы, лицензии, alt-тексты и ссылки на оригиналы сохранены из документа; удалённые страницы фотографий повторно не проверялись. См. [происхождение и лицензии фотографий](media/README.md). Фотографии не покрываются MIT-лицензией кода проекта.

Все 12 дней оформлены общим шаблоном из [PR #11](https://github.com/WorkKroG/travel-planner-skill/pull/11): жёлтая шапка, фотографии, три факта, сценарии и хронология с круглыми иконками. Необязательные `period` задают части дня без перестановки событий; технические источники вынесены в отдельный перечень сборки, а короткое авторство осталось у фото. Фактическое содержимое 242 событий сохранено; ссылки на сайты и карты дополнены, включая запасные сценарии. Объём проверки и нерешённые точки перечислены в [аудите ссылок](LINK_AUDIT.md). Открываемый результат — [HTML-маршрут](outputs/itinerary.html).

Проверка и воспроизводимая сборка из корня репозитория после установки helpers:

```sh
trip_smoke_dir="$(mktemp -d)"
cp -R examples/japan-autumn-2026 "$trip_smoke_dir/trip"
.venv/bin/travel-planner check "$trip_smoke_dir/trip"
.venv/bin/travel-planner render "$trip_smoke_dir/trip" --output "$trip_smoke_dir/japan.html" --at 2026-09-08T18:19:57+00:00
```

Для проверки команды `init` используйте отдельную временную директорию и не перезаписывайте этот пример.

Переносимый bundle включает пять канонических файлов и `media/`. Готовый `outputs/itinerary.html` уже содержит фотографии и открывается как самостоятельный файл. Пересборка с указанным временем воспроизводит committed HTML; SHA-256: `969477e6dcdfafcd08b6faa7bbc48c90ae158c42c699207fa5c2daa9e9a2cda8`. Фиксированное время нужно только для воспроизводимости примера и не означает свежую проверку поездки.

Каждая сборка создаёт `sources/<SHA256-HTML>.md` рядом с выходным HTML. [Перечень материалов этого примера](outputs/sources/969477e6dcdfafcd08b6faa7bbc48c90ae158c42c699207fa5c2daa9e9a2cda8.md) сохранён вместе с ним.
